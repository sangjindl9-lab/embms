EUM BMS PRO 현장 게이트웨이 — 설치 안내 (Windows)
=====================================================

게이트웨이는 현장 PC에서 전력계(PZEM-016, SDM120 등)를 읽어
관제 서버로 보내는 프로그램입니다. 서버가 현장 장비에 직접 접속하지 않으므로 안전합니다.
읽기만 하며, 장비에 값을 쓰거나 제어하는 기능은 없습니다.

[준비물]
 - Windows 10/11 PC (항상 켜 둘 PC)
 - USB-RS485 컨버터 (CH340 등) + 전력계 (예: PZEM-016)
 - 인터넷 연결

[0] 배선 (반드시 차단기를 내리고 작업)
 - PZEM-016: 220V 전원 연결, 부하 전선 한 가닥을 CT에 통과
 - 전력계 RS485 A → 컨버터 A(+),  B → 컨버터 B(-)
 - 컨버터를 PC USB에 꽂기 (처음이면 CH340 드라이버 설치가 필요할 수 있음)

[1] 포트 찾기
 - "1-포트찾기.bat" 더블클릭 → 표시된 COM 번호 확인 (예: COM3)
 - 아무것도 안 나오면: 컨버터 재연결, CH340 드라이버 설치, 장치관리자 → 포트(COM & LPT) 확인

[2] 장비 시험 (서버 없이)
 - "2-장비시험.bat" 더블클릭 → COM 번호 입력 → 템플릿 엔터(pzem016) → 국번 엔터(1)
 - 전압·전류 등이 "정상"으로 나오면 배선 성공
 - 모두 "실패"면: A·B 선을 서로 바꿔 보기 → 국번 확인 → 통신속도 확인 (PZEM-016 9600, SDM120 2400)

[3] 웹에서 등록  https://eumbms-web-k59f.onrender.com
 1) 사업장·게이트웨이 탭 → 사업장 추가
 2) 같은 탭 → 게이트웨이 [등록 (토큰 발급)] → 화면의 토큰(gw_...)을 복사
    ※ 토큰은 한 번만 보입니다. 잃어버리면 새로 발급하세요.
 3) 장치·태그 탭 → 장치 등록
      템플릿: PZEM-016 선택 (방식·속도·국번이 자동 입력됨)
      게이트웨이: 방금 만든 게이트웨이 선택
      시리얼 포트: [1]에서 확인한 COM 번호 (예: COM3)
 4) 장치 목록에서 [수집 시작] 클릭

[4] 설정 파일 입력
 - gateway.ini 를 메모장으로 열기 → token = 뒤에 복사한 토큰 붙여넣기 → 저장
 - "3-서버연결확인.bat" 더블클릭 → "성공: 서버 연결됨 ... 배정된 장치 1대" 확인

[5] 실행
 - "4-게이트웨이실행.bat" 더블클릭 → 창을 켜 둔 채로 두기
 - 웹 관제 화면에서 10초 안에 값이 들어오는지 확인
 - PC를 켤 때마다 자동 실행하려면 "5-자동시작등록.bat" (해제는 6번)

[참고]
 - 인터넷이 끊겨도 값은 PC에 저장(gateway_buffer.db)되었다가 연결되면 자동 전송됩니다.
 - 같은 RS485 선에 여러 전력계를 연결할 수 있습니다. 전력계마다 국번을 다르게 설정하세요.
 - 무료 서버는 한동안 접속이 없으면 잠듭니다. 처음 연결이 1분 정도 걸릴 수 있습니다.
 - Windows가 "알 수 없는 게시자" 경고를 띄우면 [추가 정보] → [실행]을 누르세요.
   (코드서명 인증서가 아직 없어서 나오는 경고입니다)
